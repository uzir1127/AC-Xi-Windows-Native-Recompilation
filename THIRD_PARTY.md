that content are outside this source release.

`dependencies/provenance.json` records the source revisions and changed runtime
paths. `dependencies/vendor-files.json` records exact bytes exported from the
local upstream dependencies, including fonts and support libraries. This allows
the source audit to distinguish those dependencies from game assets or unexpected
binaries.

The runtime's existing `--copyright` output includes additional terms for linked
components and the combined executable. This source export retains those notices
and does not present every file or a compiled game EXE as MPL-only.

The SoftFloat-derived `runtime/src/cpu/aot_wrapper/vfp/platform.h` also retains
its original Regents/SoftFloat notice; its location beside the port bridge does
not change that file's license.
